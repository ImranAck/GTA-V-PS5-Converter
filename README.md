# GTA V PS5 Converter

**Bring GTA V PC Legacy vehicle mods to compatible GTA V installations on PlayStation 5.**

GTA V PS5 Converter is an unofficial, open-source community tool for converting vehicle mods, preserving supported customizations, and preparing them for use in **offline Story Mode**.

> **Beta:** Not every vehicle or customization is supported. A completed conversion does not guarantee that a mod will work in-game.

## Features

- **Vehicle conversion** — convert supported GTA V PC Legacy add-on vehicles to PS5-compatible resources.
- **Tuning support** — keep compatible customization parts and get a clear report when optional parts are skipped.
- **Texture quality** — preserve original texture resolution where supported, without silently reducing it.
- **Automatic repairs** — detect and resolve supported model, material, and structural issues.
- **FTP installation** — optionally transfer converted packs to your PS5 over a local network.
- **Languages** — English, Spanish, and French.

## Download

Look for the latest available Windows version under **[Releases](../../releases)**. The source code is also available in this repository for anyone who wants to study or contribute to the project.

## Getting started

1. Open GTA V PS5 Converter.
2. Import the required original resources from **your own copy of GTA V PS5**. They are not included in the download.
3. Select a supported PC Legacy vehicle mod.
4. Start the conversion and review the results, including any optional parts that could not be converted.
5. Transfer the completed pack to your compatible PS5 setup manually or with the optional FTP feature.

## Compatibility

The project has primarily been developed for **GTA V PS5 PPSA04263 (version 01.010.002)** with a compatible backport and mod menu. Other game versions and setups are not yet verified.

This project is intended for **offline Story Mode only**. It is not intended for GTA Online.

## Frequently asked questions

**Does it support every vehicle?**  Not yet. Compatibility varies by mod. Unsupported optional tuning parts may be skipped with a warning; essential conversion failures will stop the process.

**Are original GTA V files included?**  No. You must provide the required original game resources from your own copy.

**Can I install converted vehicles directly?**  Yes, where supported. Optional local FTP installation requires a compatible PS5 setup with FTP access.
